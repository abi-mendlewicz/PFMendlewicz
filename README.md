# La Veterinaria

La Veterinaria es tu tienda online de confianza para todo lo que tu mascota necesita. Ofrecemos productos de calidad para el cuidado, alimentación y bienestar de tus animales, con entrega rápida y atención personalizada.

Este proyecto es una tienda en línea diseñada principalmente para una veterinaria, pero es completamente adaptable a cualquier tipo de comercio. Desarrollada con React.js, Vite, Yarn, y TailwindCSS, la aplicación permite mostrar productos, agregar al carrito, realizar pedidos y mantener la experiencia de usuario fluida y eficiente. La base de datos está integrada con Firebase Firestore para una gestión en tiempo real del stock y de las órdenes de compra.


## Características

- Catálogo de productos: Muestra los productos disponibles en la ruta raíz o filtrados por categoría en sus respectivas rutas, cargados dinámicamente desde una base de datos de Firebase.
- Detalle de productos: Cada producto tiene una vista detallada con información completa, precio, selector de cantidad y un botón para agregarlo al carrito.
- Carrito accesible: El carrito está disponible desde cualquier página, permitiendo modificar cantidades, eliminar productos o vaciar el carrito completamente.
- Vista rápida del carrito: Al agregar productos al carrito, puedes ver una vista rápida para ajustar las cantidades o eliminar artículos de manera sencilla.
- Proceso de compra: Para realizar un pedido, el usuario debe completar un formulario de compra, lo que genera una orden que se almacena en la base de datos de Firebase.
- Validación de stock en tiempo real: Utiliza transacciones de Firebase para verificar el stock de productos en tiempo real antes de generar una orden.
- Persistencia en el carrito: El carrito se mantiene persistente a través del almacenamiento local del navegador del usuario, permitiendo que la información se conserve entre sesiones.
- Estilos modernos y responsivos: La aplicación utiliza TailwindCSS para una interfaz limpia y responsiva, y React-Icons para los íconos.


## Tecnologías usadas

- React.js: Biblioteca para construir la interfaz de usuario.
- Vite: Herramienta de construcción rápida y optimizada para proyectos en React.
- Yarn: Gestor de paquetes para manejar dependencias de Node.js.
- Firebase Firestore: Base de datos en tiempo real para gestionar productos, stock y órdenes de compra.
- React Router DOM: Para la navegación entre las diferentes rutas de la aplicación.
- TailwindCSS: Framework de CSS para diseñar una interfaz moderna y responsiva.
- React Icons: Librería de íconos para una interfaz visualmente atractiva.
